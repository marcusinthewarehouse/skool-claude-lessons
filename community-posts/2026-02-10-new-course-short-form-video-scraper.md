Just dropped a new course in the Classroom: Short Form Video Scraper.

It turns TikTok videos into organized, searchable transcripts and summaries. You point it at a profile, it scrapes the videos, downloads the audio, transcribes everything locally with Whisper, and Claude summarizes it all into topic-grouped markdown files.

No API keys needed. Runs entirely through Claude Code slash commands.

What it does:

[ul][li]/start sets up the whole environment[li]/bulk processes an entire TikTok profile[li]/transcribe handles individual video URLs[li]/accounts manages multiple profiles[li]/skillify converts transcripts into reusable Claude Code skills

The course covers everything: summary of the tool, full feature breakdown, and step-by-step setup instructions with the GitHub repo link. Check it out in the Classroom under "Short Form Video Scraper".
