Just discovered this and had to share

OpenAI built an official plugin that lets you use Codex inside Claude Code. Not a wrapper, not a hack. An official repo under the OpenAI GitHub organization.

So now you've got Claude writing your code and Codex reviewing it before anything ships. Two competing AI models checking each other's work. In the same terminal.

Still playing around with it but the adversarial review mode is already interesting it doesn't just flag issues, it challenges your design decisions. Had it push back on an assumption in some dispatch logic that would have caused a silent failure under load.

Curious if anyone else is running this setup and what you're finding.
