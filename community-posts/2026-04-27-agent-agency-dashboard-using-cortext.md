Last week I was on the call and mentioned something I was working on. I have started up an agency to help people setup agent flows, but have a working dashboard using different agents with different skills to achieve outcomes. This Ui helps the user have control in the process rather than letting 1000 agents rip. This is more of a hands on feel using cortext multi agents. My approach is to give users the ability to be involved in the process of a project and to workshop with highly skilled agents with these top skills output that can 10x an employee or entrepreneurs work.
Still working on it but have added a few cool things that would be really helpful. Some of these features have been covered by others but will upload to the repo things that hasn't been added yet.
