For some quick context, I’ve been working on a GRC SaaS product for my business, SevenBelow, since 12/27/25. It’s been a wild but super fun AI ride, and Claude Code has been a godsend.

My application isn’t some simple Supabase quick-and-dirty app. It needs to be built with an enterprise and SOC 2 mindset from day one. I just wrapped up my 42nd phase, and I’ve done an enormous amount of discovery, design, and planning to get to about 70% of my MVP. Execution doesn’t really count does it?

Today I spent several hours putting together a GitHub repo to capture the madness that is my current Claude setup. It’s primarily focused around GSD, a custom skill I wrote called Checkpoint for serializing memory on human demand \(yes, it should auto-fire, but I don’t trust it enough anymore\), and a tool called CARL \(Context Augmentation & Reinforcement Layer\).

I’m a huge fan of the tools Christopher Kahler \([https://github.com/ChristopherKahler](https://github.com/ChristopherKahler)\) and Charles Dove from the CC Strategic AI Skool community have built, and I’m looking forward to testing out Chris’s PAUL orchestration tool instead of GSD. From what I’ve researched, GSD is great for sprint-type connected project work, but if you have a long, larger project — basically marathon-type work — PAUL seems to solve some of the marathon issues GSD has.

I’ll tell you this much: I’m going to be testing that theory and toolset as soon as I can wipe and reset Claude in my project repos.

If you’re interested in seeing my Claude setup, and the madness I’ve been through over the last few months, I decided to share it in a public GitHub repo. If anyone has feedback, I’d love to hear it. Feel free to be critical — this was my first Claude project, and I learned a ton.

Huge shoutout to [@James Goldbach](obj://user/d8f1c0ccde0a4784bc43b57eab7b0154) and the Agent Architects Skool. James and this community have been a major influence on my journey. I seriously can’t thank you enough.
