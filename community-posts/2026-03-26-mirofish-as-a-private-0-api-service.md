Anyone else been playing with MiroFish lately?

I've been putting together some simulation seed material for a project I'm working on and immediately ran into the obvious problem — running meaningful simulations with enough agents and rounds gets expensive fast if you're hitting cloud APIs.

Got me thinking. High unified memory hardware is getting accessible enough that a small cluster could run a 200B+ model entirely offline — zero API costs per run.

The idea: a small cooperative — maybe 3-5 people from this community — pool resources, set up the cluster, and offer offline MiroFish simulation runs as a service. NDA-backed, privacy-first, flat fee per study. Basically a boutique market analysis firm for people who don't want their sensitive strategy docs hitting someone else's API.

I'm not trying to build this solo. Looking for people who:
- Have been frustrated with API costs on simulation work
- Have hardware, infrastructure or ops experience
- Are interested in the client-facing / packaging side
- Or just think this sounds interesting and want to explore it

Not rushing into anything — want to know if others see the same problem before building anything. Drop a reply or DM me if this resonates.
