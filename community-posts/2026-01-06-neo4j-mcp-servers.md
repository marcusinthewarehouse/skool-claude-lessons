I have been reading about the MCP servers available for Neo4J. They work with either a self-hosted instance or one in Aura.

This one lets you turn a Neo4j database into a personal memory graph.
[mcp-neo4j/servers/mcp-neo4j-memory at main · neo4j-contrib/mcp-neo4j](https://github.com/neo4j-contrib/mcp-neo4j/tree/main/servers/mcp-neo4j-memory)

This one is very cool because it lets you apply graph data science + LLM approaches to graph queries without having to learn the underlying approach to implementing the queries:
[neo4j-contrib/gds-agent: MCP Server with tools from Neo4j GDS(Graph Data Science) library.](https://github.com/neo4j-contrib/gds-agent)
