I ran the Cortex OS Windows implementation as is and it required the installation of WSL and Visual Build Tools for a combined 10 GB on my machine and lots of background processes and load. During the onboard it asked me if I want to install P M2 to keep it persistent for Windows reboot. I said yes.

Look at my existing Claude Remote Manager implementation that I did earlier and then it said, "Wow this is a much simpler, much more elegant solution." It just decided to go that path entirely and then it sends a PR back with the implementation to be pulled. Keep an eye on that. This totally removes the need for the Windows Linux implementation or any visual build tools and makes it an extremely simple, elegant, more efficient, less memory, higher performance system.
