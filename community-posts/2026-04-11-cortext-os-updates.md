Been having a blast getting Cortext set up this week and I'm finally moving and grooving with my fleet of agents -- [@James Goldbach](obj://user/d8f1c0ccde0a4784bc43b57eab7b0154) this system is SO STINKIN' GOOD!

I have been adding in features for my own work purposes as I have been using it. I recorded a walkthrough of the additions I have been building. Two \(maybe three\) are basically ready for me to push to the community if there is interest. \(Let me know!\) The other three are still in flight but I should have them ready to go most likely by next week.

**Communications Hub** \(99% ready to go\)
See all communication happening across the system in one central place. Includes searching for messages, drilling into specific agent chat sessions, and the ability to chat directly within the interface with any agent \(screenshots, copy-paste into the chat, etc\). Your voice messages are transcribed and included in the chat history too.

**Deliverables Feature** \(ready to go\)
Added a Deliverables section to the task sidebar where agents can link documents \(.md files, html, images, etc\). A viewing panel appears so you can render the files on screen without digging into the file system. Shortcut buttons are on screen if you prefer to head straight to the original file.

**Projects** \(95% ready to go\)
Added a Projects page where agents are required to maintain project folders to organize their tasks into. The Projects page is essentially a filing cabinet so all tasks related to a specific project can be surfaced and drilled into from one place at once.

**Approval Workflow** \(70% ready to go\)
Multiple approval workflow options that require agents to submit work for approval. Includes automated routing, notifications, and the ability to leave feedback and send tasks back to the agent for revisions. Adds a Needs Review column to the Tasks page \(if the user turns on reviews\) and routes approvals to the Approvals page. Still under development but coming along nicely.

**Design Personalization and Polish** \(80% ready to go\)
