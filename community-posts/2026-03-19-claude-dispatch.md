Claude just released Dispatch. The remote-control for Cowork. I believe it's currently available on Max/Pro plans for now. It essentially lets you use Claude on your desktop from your phone, so you can still access your files, plugins, and connectors. It includes a feature to keep your computer awake. Between this, remote-control, and the loop feature/scheduled tasks, they're slowly putting together their own OpenClaw. It'll be interesting to see how this actually gets used.

The current limitations are too restrictive for some workflows. The biggest one, for me, is that you can't start new threads. Although it does remember previous tasks. Other limitations are:
[ul][li]Desktop must be active \(which they address with the feature to keep your computer awake\)[li]Claude only responds to messages and works on tasks you give it. It can't proactively reach out to you.[li]It can't manage scheduled tasks. It can run existing tasks, but can't create new ones.

I'm sure they'll keep building on it. I'm probably still going to use remote-control and Claude Code on the web more, with how I use Claude. I'm interested in hearing what you guys think and any interesting use cases.

One thing to note is that the documentation says you can't manage scheduled tasks, but the desktop app says you can run them. I interpreted that as being able to run existing scheduled tasks, but not create new ones or manage existing ones. I haven't tested it yet.
