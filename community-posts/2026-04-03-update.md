Hey Architects,

My apologies for being a bit absent in the community and on socials the past few days. I have been absolutely neck deep in Cortext trying to get it production ready for you all to use out of the box.

Nearing the end now, very excited to see what you all think. It will certainly be rough around the edges at first in terms of installs, and fixing all the edge cases I'm sure you will all encounter, but with your help it will become polished up in no time.

I've rebuilt the entire system on Node.js so everyone can use it, Windows, Mac and Linux.

To give you a brief description of what the system is shaping up to be:

Cortext is designed to be a self improving multi-agent workspace that you can use remotely from all your devices.

The core system is built around the idea of organizations, groups of specialized agents that have shared goals. Right now the system only runs with Claude code, but will soon support adding other agents as well \(codex, openclaw, hermes, pi agents, etc\). You can create as many organizations as you want, each with as many agents as you want.

Each agent is a fully featured Claude Code session that runs 24/7 and is accessible via Telegram to chat with. You can use all of the Claude code features you're used to in the terminal directly from telegram. I am in the process of developing a native iOS app that connects to your system with native agent chat + Cortext dashboard for full integrated control. Agents can message directly with you through their own channel, as well as message any other agent in the system, all with <3s delay.

Each organization shares a task management system \(like Linear, Jira, Notion\), that gives agents the ability to work off of tasks lists that you create, and that agents create for each other. They will ask you for approvals, and can assign tasks to you that they need your help with.

Each agent has its own "workflows". These are defined in cron trigger + skill pairs \(e.g., at 8AM every morning, scrape the claude code github repo for new updates and draft a post in Skool about them\).
