been seeing a lot of people setting up openclaw and similar stuff, figured i'd share what i built. it's a self-hosted telegram bot that runs claude code on a VPS. persistent memory, web browsing, full system access, reads images and docs you send it, sends you screenshots of whatever it's looking at in real time.

the thing that makes it click for me is the memory system. it keeps facts, daily logs, chat summaries, so every session picks up naturally. no re-explaining. just text it like a friend and it handles stuff.

runs on a claude max sub so no API cost surprises. one command install on any ubuntu VPS.

open sourced the whole thing: [https://github.com/aflekkas/lobster-bot](https://github.com/aflekkas/lobster-bot)

would appreciate a star if you check it out, and lmk if you build anything with it 🙂
