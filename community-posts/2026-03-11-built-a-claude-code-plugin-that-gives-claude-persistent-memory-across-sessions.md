Hey Agent Architects! I built something I think you'll find useful.

BizBrain OS is a Claude Code plugin that builds a persistent knowledge brain from your actual work. Think of it like compound interest for AI context — every session deposits knowledge, every future session withdraws it.

What it does:
[ul][li]21 skills \(entity management, project tracking, GSD workflows, knowledge management, browser automation, and more\)[li]- 4 agents \(brain orchestrator, entity watchdog, brain gateway, brain learner\)[li]- 13 slash commands \(/brain, /todo, /knowledge, /gsd, /intake, /comms, etc.\)[li]- 5 profiles \(developer, content-creator, consultant, agency, personal\)[li]- Brain Swarm for multi-agent coordination with smart model routing
It's open source, local-first, and free. Your data never leaves your machine.

Install: claude plugin add TechIntegrationLabs/bizbrain-os-plugin
Website: [bizbrainos.com](http://bizbrainos.com)
