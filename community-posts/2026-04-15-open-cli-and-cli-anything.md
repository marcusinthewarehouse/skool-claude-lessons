I added both of these today. In my opinion, it’s a lot better than Playwright. Since it runs locally on your Mac, Windows machine, or server using the Chrome CLI plugin, it significantly reduces token usage compared to a Playwright setup that relies on AI-driven browser control. Then you can just use CLI commands and you’re good to go, even with software that doesn’t have an API.

This also helps solve the headless browser issue that can get you flagged or blocked on platforms like AppFolio, since it runs through a real Chrome instance instead of a headless environment.
