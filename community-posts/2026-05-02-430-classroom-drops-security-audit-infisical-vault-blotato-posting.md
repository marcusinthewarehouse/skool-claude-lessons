3 new resources just dropped in the Classroom \(Tools and Skills\):

Agent Security Audit Skill -- A deep audit prompt that scans your Claude Code agents for the most common vulnerabilities: prompt injection, credential exposure, unvalidated inputs, privilege escalation. Run it on any agent to get a full threat model.

Infisical Vault Skill -- Pulls secrets from Infisical into your agent at runtime so API keys never live in .env files. Keys are fetched on demand, never written to disk, and every access is logged.

Blotato Posting Skill -- Lets Claude Code post videos to TikTok, Instagram, YouTube, LinkedIn, and X in one command. Point it at a video file and a caption, it handles the rest.

All 3 are in the Classroom under Tools and Skills.
