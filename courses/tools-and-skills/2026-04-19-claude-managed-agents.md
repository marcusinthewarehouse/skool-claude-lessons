Anthropic just launched Claude Managed Agents in beta. This is the hosted platform for deploying persistent agents via API — full sandbox, bash access, file system, MCP servers, multi-agent coordination, and credential injection via Vaults. This doc is the complete reference: every endpoint, event schema, tool config, and three creative end-to-end implementation examples. This is API-only access right now. No UI.
