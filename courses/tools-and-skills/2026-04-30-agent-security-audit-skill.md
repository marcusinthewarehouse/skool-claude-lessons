Agent Security Audit is a deep audit prompt that scans your Claude Code agents for the most common security vulnerabilities.

Run it on any agent to get a full threat model: prompt injection vectors, credential exposure, unvalidated inputs, privilege escalation paths, and output trust issues. Built from real vulnerabilities found in production agent deployments.

What it audits:

- Prompt injection: user-controlled inputs that can hijack agent behavior
- - Credential exposure: API keys and secrets accessible to the agent
- - Unvalidated inputs: data from external sources treated as trusted
- - Output trust: downstream systems acting on unverified agent outputs
- - Privilege escalation: tools that exceed the agent's intended permissions
