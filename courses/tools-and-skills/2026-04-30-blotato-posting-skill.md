Blotato Posting Skill lets Claude Code post videos and content to TikTok, Instagram, YouTube, LinkedIn, and X in one command.

Point it at a video file and a caption and it handles upload, format conversion, and platform submission. Stripped from the distribute skill into a standalone posting tool any agent can use.

What it does:

- Uploads video files directly to Blotato via the v2/posts API

- Posts to TikTok, Instagram Reels, YouTube Shorts, LinkedIn, and X simultaneously

- Handles file compression for platform size limits

- Returns post IDs for each platform for tracking
