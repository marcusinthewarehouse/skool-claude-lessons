This video walks you through the full OpenClaw installation and onboarding process - from creating a dedicated user account to sending your first message.

**What you'll set up:**

- **Dedicated user account** - A fresh OS user just for OpenClaw (not your admin account).
- **Installation** - Install OpenClaw and run the onboarding wizard with `openclaw onboard --install-daemon`.
- **Permissions** - Grant Automation, Notifications, and other system permissions.
- **AI model** - Connect your Anthropic API key (recommended), ChatGPT, or Kimi K2.5.
- **Workspace** - Understand the three key locations: workspace, system config, and the installed code.
- **Telegram** - Create a bot via BotFather and send your first message to your AI assistant.

**Three ways to interact:**

- **Telegram** - Message your assistant from your phone, anywhere.
- **TUI** - Terminal chat interface with `openclaw tui`.
- **Web Dashboard** - Full control center at localhost:18789 with `openclaw dashboard`.
