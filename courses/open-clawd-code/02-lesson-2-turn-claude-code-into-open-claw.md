## What You'll Learn

- How to give your agent a distinct personality and identity
- The 7-file system that defines who your agent is
- Running the onboarding wizard to set everything up in one command
- Setting up daily memory and a 30-minute heartbeat for proactive check-ins
- The reversible vs irreversible rule for agent autonomy

## In This Lesson

Your agent from Lesson 1 responds like a stranger - generic, no context, no personality. In this lesson, you'll transform it into a personalized agent that knows its name, understands your preferences, tracks what it does daily, and proactively checks in every 30 minutes even when you're not talking to it.

You'll use the onboarding skill to walk through an interactive setup wizard that creates all 7 identity files: IDENTITY.md, SOUL.md, USER.md, TOOLS.md, MEMORY.md, HEARTBEAT.md, and the master CLAUDE.md that bootstraps everything.
