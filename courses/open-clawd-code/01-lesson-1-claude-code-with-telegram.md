### What You'll Learn

By the end of this lesson, you will have a working Claude Code bot you can text from your phone that does real things on your computer. No prior experience needed.

### In This Lesson

- Create a Telegram bot via BotFather
- Build check-telegram.sh and send-telegram.sh scripts
- Set up /loop polling to check for messages every minute
- Lock your bot to only respond to your Telegram account
- Send your first message and get a real reply from Claude Code
