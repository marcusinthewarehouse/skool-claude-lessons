Configuring Allowed Tools
Edit settings.json to pre-approve specific operations:
{
  "permissions": {
    "allow": [
      "Read", "Glob", "Grep",
      "Bash(npm run:*)",
      "Bash(npm test)",
      "Edit(/src/**)",
      "Edit(/tests/**)"
    ]
  }
}
Pattern Syntax

Pattern
Meaning
Bash(npm run:*)
npm run followed by anything
Edit(/src/**)
Edit any file in src (any depth)
Read
All read operations
Setting Up Deny Rules
Deny rules are your safety net — they block even if something would otherwise be allowed:
{
  "permissions": {
    "deny": [
      "Read(./.env)",
      "Read(./.env.*)",
      "Read(./secrets/**)",
      "Bash(rm:*)",
      "Bash(sudo:*)",
      "Bash(curl:*)"
    ]
  }
}
Always Deny
	•	.env files
	•	secrets/ directories
	•	SSH keys
	•	AWS credentials
	•	Destructive commands (rm, sudo)
