Understanding Permissions
What This Lesson Covers
How Claude Code asks for permission before making changes, what each option means, and how to control the permission mode.
The Trust Prompt
First time you run Claude Code in a new folder, you'll see:

"Do you trust the files in this folder?"

	•	Click Yes for your own projects
	•	This only appears once per folder
	•	Stored in the .claude folder

Bash Command Permissions
When Claude wants to run a terminal command, you'll see the exact command before approving.

Always read the command first.

Safe Commands

The Key Rule
"Yes, all edits this session" is the sweet spot:

	•	Moves fast without constant popups
	•	Still shows you what changed
	•	Resets when you close Claude Code

Warning: Don't leave acceptEdits mode on and walk away — Claude will keep working.
