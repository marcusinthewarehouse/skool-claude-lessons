Hey everyone! Just wrapped up another great community call and wanted to share the highlights for those who couldn't make it. Here's a rundown of what we discussed:

## AI Video Generation is Getting Insane

- Seedance 2.0 from ByteDance is producing near Hollywood-level scenes from prompts
- AI-generated content (image, video, audio) is becoming the second highest-leverage use case after coding
- The fight scene between Brad Pitt and Tom Cruise generated by AI was brought up as an example of how far things have come

## The Job Market Conversation Got Real

- Microsoft's AI chief predicting all white-collar work could be replaced within 18 months
- Bryan shared a wild story from his company where 3 developers using Claude are actively replacing 9 other programmers on their team - and they were upfront about it
- A friend of Sam's saw ~20 developers laid off at a local company pursuing an "AI forward strategy"
- Dario Amodei (Anthropic CEO) introduced the "Centaur" concept - developers becoming half-human, half-AI for the foreseeable future
- Honest talk about the stress and uncertainty everyone feels, even those of us deep in the AI space

## Corporate AI Adoption is Still a Mess

- Bryan's cybersecurity team shut down his AWS VM because Hugging Face downloads freaked them out
- DeepSeek models getting flat-out banned at some corporations
- Claude Team billing requiring 5 licenses minimum is a pain point
- A lot of developers at companies are secretly using AI but not admitting it

## OpenClaw and The Future of Autonomous Agents

- OpenAI reportedly hired Peter Steinberger (OpenClaw creator) for around $1 billion
- Using Anthropic API with OpenClaw is expensive but the most reliable/secure option
- Security is the biggest unsolved problem with autonomous agents accessing personal data
- James recommends learning Claude Code first before jumping to OpenClaw - understanding context engineering is essential for steering agents correctly
- OpenClaw course coming to the community in the next few weeks

## Claude Code as a Personal OS

- Using Claude Code as the first thing you open on your computer
- On Mac, OSA scripts let Claude Code control Apple apps (Calendar, Mail, Messages) programmatically
- The future is agents making API calls instead of humans using app interfaces
- SaaS companies will need to make their products agent-friendly

## GSD Framework and Custom Workflows

- Get Shit Done (GSD) is a great starting point but building custom versions per project works even better
- James's workflow: Idea -> PRD -> Q&A -> External Research -> Agent Environment Engineering -> Task Sharding
- The key addition: having Claude Code evaluate what MCPs and custom skills to set up before development even starts
- Iman built a Shopify-specific version of GSD that's been working well

## SLMs (Small Language Models) on Device

- Benjamin attended an Andrew Ng conference focused on SLMs running locally on personal devices
- Personal on-device models = better privacy, no cloud dependency
- The future likely involves everyone having their own personal AI brain on their device
