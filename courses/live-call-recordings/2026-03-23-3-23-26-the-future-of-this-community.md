## Reverse Prompting / Meta Prompting

- Technique: feed your rough idea into an LLM and ask it to create a better prompt, then use that refined prompt for your actual task
- Works because LLMs function like role play partners - specific technical words activate different neural pathways and produce better outputs
- Wyatt's hack: ask the AI to "analyze what we've got here with a critical eye" - triggers a completely different evaluation mode vs the default people-pleasing mode
- Can be built as a slash command/skill in Claude Code that reformats your raw input into an optimized prompt for any platform
